# Bicycle repair

Maquette fictive — [Memory](../../../home.md).

## Scope

Une roue arrière qui frotte empêche les trajets domicile-travail à vélo.
Le bus remplace ces trajets dans la parole du 3 février 2026.
[S9](../../../sources.md#s9).

## Last confirmed state

**Non résolu**, confirmé le 6 mai 2026. Recherche d’un atelier équipé, sans
créneau obtenu à cette date. [S11](../../../sources.md#s11).

## History

- 3 février, signalement : roue arrière qui frotte et vélo inutilisable pour
  aller travailler. [S9](../../../sources.md#s9).
- 12 février, retour sur les tentatives : le réglage des freins n’a rien
  changé ; le premier réparateur n’avait pas le matériel nécessaire. Les
  dates exactes de ces deux tentatives ne sont pas fournies.
  [S10](../../../sources.md#s10).
- 6 mai, confirmation : le problème persiste et aucun créneau n’a été trouvé.
  [S11](../../../sources.md#s11).
