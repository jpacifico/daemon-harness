# Capsule: examples/restaurant_simple
Sujet: Exemple non personnel pour une idée simple de restaurant ou de dîner.
Portée: capsule de test et de démonstration autour d'une demande de restaurant simple.
Hors portée: préférences alimentaires personnelles réelles, repas réellement mémorisés.

## Faits
- Capsule non personnelle destinée aux tests et aux démos.
- Utile quand l'utilisateur demande une idée de restaurant simple pour un dîner.
- Angle de réponse possible : proposer une option claire, légère, puis demander le quartier si nécessaire.
